The original museum illustration assets come from the user-provided
`stitch_remix_of_vi_t_ph_c_studio_platform.zip` design export.

- `gallery.jpg`: museum page hero image.
- `giao-linh.jpg` and `nhat-binh.jpg`: matching collection illustrations.
- `nhat-binh-detail.jpg`: illustration from the detail page design.

These are design illustrations, not authenticated artifact photographs.
The UI prefers curated local assets for these six records so that no human faces
appear in the museum, wardrobe, or outfit suggestions. New catalog records without
a local match use their API image. There are no visible illustration badges.
