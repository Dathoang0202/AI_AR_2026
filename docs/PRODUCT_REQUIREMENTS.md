# Việt Phục Studio — Product Requirements Document (PRD)

## Product Overview
Việt Phục Studio is an intuitive, culturally verified web application dedicated to Vietnamese traditional clothing (Áo Nhật Bình, Áo Giao Lĩnh, Áo Tấc, Áo Ngũ Thân, Áo Dài).

## Scope & Vertical Slices

### Slice 1: Core Outfit Experience (COMPLETE)
- **Homepage**: Responsive hero area, product introduction, outfit showcase, CTAs.
- **Onboarding Quiz**: Interactive questionnaire collecting occasion, region, style, colors.
- **Recommendation Engine**: Generates structured outfits with primary garment, accessories, colors, cultural context.
- **Outfit Studio**: Real-time customization, live cultural validation status, save outfit action.
- **Cultural Validation Engine**: Rule-based checking against historical records (Khâm Định Đại Nam Hội Điển Sự Lệ, Ngàn Năm Áo Mũ).
- **Save Outfit**: User authentication and persistent Lookbook storage.

### Slice 2: Cultural Encyclopedia
- Interactive search, filtering by category (Garments, Regions, Periods), detailed citations.

### Slice 3: Location & Rental
- Provider directory, geolocation support, rental items availability.

### Slice 4: Personal Lookbook
- Authenticated user lookbook management (Edit, Delete, Privacy settings).

### Slice 5: AI Cultural Assistant
- AI-driven conversational Q&A using validated cultural knowledge retrieval.
